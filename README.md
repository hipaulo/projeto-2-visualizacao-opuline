## 📊 Sobre o projeto
Dashboard desenvolvido para a **Opuline Cosméticos** durante o curso **"Power BI: visualizando e analisando dados"** da Alura.

**Métricas analisadas:**
- Faturamento total: R$ 714 mil
- Itens vendidos: 2.103
- Ticket médio: R$ 6,34 (meta: R$ 8,00)

## 🎯 Principais análises
- Evolução do faturamento por ano
- Distribuição por localidade
- Comparativo com metas estabelecidas

## 🛠️ Ferramentas utilizadas
- Power BI Desktop
- Visualizações nativas
- Gráficos de barras, linhas e KPIs
